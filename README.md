# PINCAR · 校寝拼车通勤

<img src="assets/pincar-avatar.png" alt="PINCAR 小程序头像" width="104">

PINCAR 是一个微信小程序，帮助在「科学智汇城 ↔ 港城莞」之间通勤的乘客找到同方向的队友。乘客可以先组队再叫车、加入已叫到车的队伍，或提前发布出发计划。车辆由乘客在其他平台自行叫取。

## 功能

| 入口 | 可以做什么 |
| --- | --- |
| 我要拼车 | 选择通勤方向，自动加入最多四人的队伍，用当天唯一的四位暗号和队友碰面。 |
| 我已叫车 | 发布车牌尾号、南门或北门、预计到达时间，同方向乘客可以确认加入。等待组也可以填车牌，整队转为已叫车组。 |
| 预约拼车 | 发布至少 30 分钟后的出发时间，按方向、集合门和时间组织同行。 |

首页以「起点 → 终点」展示两条路线。大厅将预约入口放在第一行，两个即时入口并列。小程序包含首次使用指南、隐私说明，以及退出队伍、确认出发和结束行程的操作。

## 本地体验

1. 将本目录作为「小程序」项目导入微信开发者工具。使用游客模式，或选择自己的小程序 AppID。
2. 点击「编译」，完成新手指南，输入测试昵称并同意隐私说明，然后选择通勤方向。
3. 可加入示例车辆、创建即时队伍，或发布预约。演示数据保存在当前设备，跨设备同步需要配置云开发。

多人联机的环境配置、数据库索引、权限和部署步骤见[云开发配置](CLOUD_SETUP.md)。

## 实现

- **原生微信小程序**。页面使用 WXML、WXSS 和 JavaScript。服务层提供本地存储与微信云函数两种实现。
- **组队并发与暗号分配**。云端通过数据库事务维护组员和活动队伍，用日期与暗号组合键登记暗号。确认出发后，车辆退出大厅展示。
- **访问控制与期限**。客户端通过云函数访问业务数据。服务端检查小程序身份、请求参数和频率。等待队伍与已叫车信息设有过期时间，预约到出发时间后退出列表。

```text
pages/                首页、大厅、队伍、预约、指南、隐私
services/             本地演示与云端调用
cloudfunctions/pincar  组队、车牌和预约云函数
utils/                通勤路线与时间常量
tests/                本地业务流程与服务端规则测试
```

## 测试

在仓库根目录运行以下命令。两套测试都可直接用 Node.js 运行。

```sh
node tests/local-flow.test.js
node tests/security.test.js
```

本地流程覆盖双向隔离、四人上限、暗号、车牌与集合信息、预约、退出、发车与过期。服务端规则测试覆盖格式校验和限流。
